# قالب سابسکریپشن مرزبان — Homa Ghost 2

نسخه پایدار: `2.1.0`

یک قالب فارسی، مدرن، سریع و کاملاً واکنش‌گرا برای صفحه اشتراک مرزبان؛ با دو پوسته تاریک و روشن، آموزش مرحله‌ای کلاینت‌ها و نصب‌کننده‌ای که پیش از تغییر فایل‌ها بکاپ می‌گیرد.

## امکانات اصلی

- طراحی تازه و Mobile-first برای موبایل، تبلت و دسکتاپ
- پوسته تاریک و روشن با ذخیره انتخاب کاربر و تشخیص تنظیم سیستم
- نمایش دقیق وضعیت‌های فعال، اتمام حجم، منقضی، غیرفعال و در انتظار شروع
- حجم مصرف‌شده، باقی‌مانده، درصد مصرف، تاریخ پایان، چرخه ریست و آخرین اتصال
- نمودار مصرف واقعی در بازه‌های ۷، ۱۴ و ۳۰ روز از endpoint رسمی `/usage`
- نمایش مجموع مصرف و پرمصرف‌ترین نود در بازه انتخابی
- تاریخچه محلی جایگزین، اگر `/usage` از پشت CDN یا فوروارد سابسکریپشن قابل دسترس نباشد
- بروزرسانی بدون Reload از endpoint رسمی `/info`
- QR داخلی برای لینک اشتراک و تک‌تک کانفیگ‌ها، بدون وابستگی اجرایی به CDN
- کپی لینک اصلی، کپی کانفیگ تکی و کپی همه کانفیگ‌ها
- تشخیص Android، iOS، Windows، macOS و Linux
- ورود یک‌کلیکی در کلاینت‌هایی که Deep Link معتبر دارند
- آزمایش اختیاری دانلود، آپلود، پینگ و جیتر؛ فقط بعد از کلیک کاربر
- بخش رفع خطا برای مشکلات رایج Android، iOS و Windows
- نوار دسترسی سریع موبایل، ناوبری صفحه‌کلید و پشتیبانی از Reduced Motion
- بدون ردیاب، تبلیغات و کتابخانه ظاهری خارجی
- نصب‌کننده با بکاپ خودکار و Rollback در صورت شکست

## کلاینت‌های آموزش‌داده‌شده

| سیستم‌عامل | کلاینت‌ها |
|---|---|
| Android | Hiddify، v2rayNG، Happ، V2Box |
| iOS / iPadOS | Hiddify، Happ، Streisand، V2Box، Shadowrocket |
| Windows | Hiddify، Happ، v2rayN، Clash Verge Rev |
| macOS | Hiddify، Happ، v2rayN، Clash Verge Rev |
| Linux | Hiddify، Happ، v2rayN، Clash Verge Rev، v2rayA |

برای هر کلاینت چهار مرحله نصب، افزودن اشتراک، بروزرسانی و اتصال نوشته شده است. لینک دانلودها به فروشگاه یا مخزن رسمی همان برنامه اشاره می‌کنند.

## سازگاری با مرزبان

قالب از فیلدهای رسمی صفحه Subscription استفاده می‌کند:

- `user.username`
- `user.status.value`
- `user.used_traffic`
- `user.data_limit`
- `user.expire`
- `user.data_limit_reset_strategy.value`
- `user.subscription_url`
- `user.online_at`
- `user.on_hold_expire_duration`
- `user.links`

مسیرهای هم‌دامنه استفاده‌شده:

- `/{token}/info`
- `/{token}/usage`
- `/{token}/clash-meta` برای ورود به Clash Verge Rev

## نصب سریع روی سرور

فایل ZIP را استخراج کن، وارد پوشه قالب شو و اجرا کن:

```bash
chmod +x install.sh
sudo ./install.sh
```

نصب‌کننده این کارها را انجام می‌دهد:

1. وجود فایل‌ها و ساختار Jinja را بررسی می‌کند.
2. از قالب فعلی، QR محلی و فایل `.env` بکاپ می‌گیرد.
3. فایل‌ها را در `/var/lib/marzban/templates/subscription/` قرار می‌دهد.
4. تنظیمات زیر را در `/opt/marzban/.env` ثبت یا بروزرسانی می‌کند.
5. مرزبان را ری‌استارت می‌کند؛ اگر کاری شکست بخورد نسخه قبلی را برمی‌گرداند.

```env
CUSTOM_TEMPLATES_DIRECTORY="/var/lib/marzban/templates/"
SUBSCRIPTION_PAGE_TEMPLATE="subscription/index.html"
```

اگر فایل `.env` جای دیگری است:

```bash
sudo MARZBAN_ENV_FILE="/path/to/.env" ./install.sh
```

## تنظیم پشتیبانی و برند

در انتهای `index.html` مقدارهای `APP_CONFIG` را می‌بینی:

```js
brandName: "هما گوست",
supportUrl: "https://t.me/YourSupport",
channelUrl: "https://t.me/bank_v2ray"
```

پیش از نصب، `YourSupport` را با آیدی واقعی پشتیبانی عوض کن. تا وقتی این مقدار تنظیم نشده باشد، دکمه پشتیبانی به بخش رفع مشکل همین صفحه هدایت می‌شود و هیچ آیدی اشتباهی باز نمی‌شود.

Endpointهای تست سرعت نیز در همین بخش قابل تغییرند. سرویس جایگزین باید HTTPS و CORS مناسب داشته باشد.

## رفتار نمودار مصرف

قالب برای هر روز بازه یک درخواست هم‌دامنه می‌فرستد، ولی هم‌زمانی را به چهار درخواست محدود می‌کند تا به سرور فشار ناگهانی وارد نشود. مصرف همه نودها جمع می‌شود و نام پرمصرف‌ترین نود نمایش داده می‌شود. اگر endpoint آمار پاسخ معتبر ندهد، صفحه بدون خطا به تاریخچه محلی مرورگر برمی‌گردد و منبع داده را صریح زیر نمودار می‌نویسد.
